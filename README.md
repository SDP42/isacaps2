# MIRAGE

**Multimodal Impersonation & Request-Aware Guard Engine** — Team Outliers · D3COY 1.0 · DJS ISACA · PS-02
*AI-Based Deepfake-Enabled Social Engineering Detection*

> Seeing is no longer believing.

MIRAGE investigates a suspicious communication — a voice note, a video call clip, an image, an email or chat
message, or all of them together — and answers the question that actually matters: **is it safe to act on this request?**

Five evidence *witnesses* (Voice, Face, Words, Identity, Provenance) testify. A multi-agent *Tribunal* argues the
case, including a Skeptic who looks for innocent explanations. A transparent, request-aware risk engine returns
Low / Medium / High / Inconclusive with the exact evidence, and a verification plan routes the user to an
independent channel before money or credentials move.
