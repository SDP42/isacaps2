# Credentials and OTPs
Never share passwords, one-time passwords or MFA codes with anyone, including IT staff. The Service Desk will never ask for an OTP by phone, chat, email or video.

# Password resets
Resets are self-service through the identity portal or raised as a ticket on the IT portal. A reset requested by phone or video requires the employee's manager to confirm the request on a directory number.

# Remote access
Remote support uses only the managed tool launched from the IT portal. Requests to install AnyDesk, TeamViewer or similar tools are to be refused and reported.

# Reporting
Report suspected impersonation to the security team. Analysts can open the case in MIRAGE with the original files so hashes are preserved.
